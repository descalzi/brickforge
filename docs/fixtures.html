Using the fixtures

  1. Download an STL model using the link above.
  2. Open the Mesh Inspector and select the downloaded file.
  3. Keep source units set to millimetres unless deliberately testing unit conversion.
  4. Record the detected openings, warnings, voxel grid and construction result. Compare them with the intended features in the fixture catalogue.

Download the machine-readable fixture catalogue (JSON).

These are deterministic, 1 mm voxel-derived meshes. They are excellent for repeatable regression and workflow tests, but their surfaces are quantised rather than CAD-perfect. The catalogue records intended features, not a promise that every current heuristic will detect them perfectly.
