Mesh input

The file is read locally in this browser. It is not uploaded to a server.

Browse the STL validation fixture library — includes holes, angled and curved tunnels, branching passages and a car-shaped test model.

STL and OBJ files do not reliably declare their units. The initial assumption is millimetres; change this if your model was exported in centimetres, metres or inches.

The construction grid uses Y as its vertical course axis. Choose the source axis that should become vertical. For a flat plate whose thickness runs along Z, choose Z-up. The mesh is rotated without changing its scale.

Use plate courses for thin targets and shallow trays. The horizontal stud pitch remains 8 mm; plate mode uses matching 3.2 mm-tall plate profiles.
