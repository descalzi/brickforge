02 / THE PIPELINE

The object comes first.

  1. Specify intent

    Components, dimensions, shapes, empty spaces and relationships. An optional language model produces this contract; it does not guess part numbers.

  2. Find and fit elements

    Search capabilities and source profiles, explore rigid orientations and combine compatible parts. Exact dimensions stay exact unless a brief permits a bounded adjustment.

  3. Check the assembly

    Inspect the mating graph, body envelopes, support projection and nominal approach checks. Unsupported requirements and unverified physics stay visible.

  4. Build on the result

    Inspect individual steps, edit components, save browser-local revisions, and export LDraw, the parts list, a full report and a vector instruction PDF.

03 / WHAT THE RESULT MEANS

A checked candidate,
with its limits in view.

The current catalogue is curated. It covers standard structural parts and selected slopes, frames, wheel assemblies, round elements and wings. Arbitrary objects, joints and surfaces can still be rejected.

Connection checks are nominal. The support calculation uses a simplified volume proxy; approach checks exclude studs, cavities, deformation and hand access. Physical clutch, strength, rolling performance and structural stability require further evidence.

No hosted language service is bundled. The studio can export an interpretation request or use a gateway you configure. Construction itself stays in your browser.
