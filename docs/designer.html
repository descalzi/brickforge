BF / DESIGN-ENGINE-01

Describe the object.
Let the planner solve the build.

This is the first deterministic construction-engine workbench. Its input describes the intended object in millimetres, without prescribing LEGO part IDs or placements. The browser searches the available part profiles, solves exact course layouts, checks nominal interfaces and produces a BOM and LDraw model.

Catalogue-independent design specification

The specification is an object description, not a build recipe. Dimensions must currently align to the 8 mm stud pitch and the selected 9.6 mm brick or 3.2 mm plate course height.
